# Accessibility & Architecture Audit

## Project Overview

This project audits a public-facing website for accessibility issues and creates a maintainable full-stack project foundation.

## Audited Website

Website: ConfirmTkt – Train Ticket Booking

## Audit Method

The website was tested using:
- Google Lighthouse Accessibility Audit
- Keyboard-only navigation
